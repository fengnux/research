## 踩坑紀錄

### GitHub Release rate limit

執行 `tenv tm install latest` 下載 Terramate 時，因 GitHub API 未認證請求的 rate limit（60 req/hr）觸發限制，導致下載失敗。

**解法：** 建立 Fine-grained Personal Access Token，設定環境變數：

```bash
# ~/.zshrc
export TENV_GITHUB_TOKEN="your_token_here"
```

## 重要發現

- tenv 除了 OpenTofu，也支援 Terramate（`tenv tm`），不需要額外安裝其他版本管理工具
- tenv 支援的工具：OpenTofu、Terraform、Terragrunt、Terramate、Atmos
- `gh skill install` 是 gh CLI 原生支援的指令，可直接安裝 Claude Code skill，無需手動下載

### gh skill install 用法

```bash
# 安裝 skill 至 user scope（所有專案皆可使用）
gh skill install <owner/repo> <skill-name> --agent claude-code --scope user

# 覆蓋已存在（或損壞）的 skill
gh skill install <owner/repo> <skill-name> --agent claude-code --scope user --force
```
