## 踩坑與政策調整

### 坑一：`.terraform.lock.hcl` 跨平台 hash 衝突

第一次 PR workflow 失敗，錯誤訊息：

```
Error: repository has uncommitted files
> execution failed: running tofu validate (in /stacks/dev/vm): exit status 1
```

排查：本機在 macOS（`darwin_arm64`）init，lock file 只記了 darwin 的 hash；CI 在 Linux runner（`linux_amd64`）跑 `tofu init` 會自動補上 linux 平台的 hash 進 lock file，導致 working tree 變 dirty，後續 `terramate run` 的 git-uncommitted safeguard 直接 fail。

**解法**：採用 Terramate 官方範例 [`terramate-github-actions-example`](https://github.com/terramate-io/terramate-github-actions-example) 的做法 —— **`.terraform.lock.hcl` 列入 gitignore，不入 repo**。

調整：

- `git rm --cached` 5 個 stacks 的 lock files
- 改 `iac/docs/toolchain.md`「Provider Lock File 政策」段落，明確記錄此權衡（失去供應鏈 hash 驗證 vs 避免跨平台 hash 衝突）
- 移除原本規劃的 "two-commit pattern"（IaC commit + lock file commit）

commit [306b4d8](https://github.com/fengnux/tofu-terramate-lab/commit/306b4d8)

### 坑二：bootstrap stack 也不該由 CI apply

修完 lock file 政策後，main push workflow 仍 fail：

```
Error: storage.buckets.get access ... denied on bucket research-lab-495809-tofu-state
```

原因：上一個 commit 變更涵蓋 `stacks/bootstrap/` 目錄，CI 把 bootstrap 也納入 changed stacks。但 CI SA 只有 `storage.objectAdmin`（讀寫 state 物件），沒有 `storage.admin`（管理 bucket 本身）—— 也不該有，畢竟 CI 不應能修改自己用的 state bucket。

**解法**：用 `foundational` tag 統一標記「不該由 CI 處理」的 stack。

- bootstrap 已有 `tags = ["bootstrap", "foundational"]`
- WIF stack 從 `["ci", "wif"]` 改為 `["ci", "wif", "foundational"]`
- workflow 全部 `--no-tags wif` 改為 `--no-tags foundational`
- detect job 改名 `detect-foundational-changes`

commit [fabaf14](https://github.com/fengnux/tofu-terramate-lab/commit/fabaf14)

### 踩坑：plan-output.md 觸發 git-untracked safeguard

第一次 PR push 後 plan job 立刻 fail：

```
Error: repository has untracked files
##[error]Process completed with exit code 1.
```

原因：原本把 `plan-output.md` 寫在 workspace 內（cwd），`terramate run --changed -- tofu plan` 的 git-untracked safeguard 偵測到後直接拒絕執行——後續 `tofu plan` 根本沒跑。

解法：把輸出檔位置改成 `${{ runner.temp }}/plan-output.md`，完全避開 workspace。`sticky-pull-request-comment` 的 `path:` 欄位接受絕對路徑。

修法 commit：[e7b9858](https://github.com/fengnux/tofu-terramate-lab/commit/e7b9858)（已被 squash 進 [eb32c41](https://github.com/fengnux/tofu-terramate-lab/commit/eb32c41)）
