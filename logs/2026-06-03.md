# 2026-06-03 實驗日誌

## 目標

重新規劃 [`evidence-pack-foundation`](../audit/labs/evidence-pack-foundation.md) 的執行環境：新的 DuckDB / Trivy / GCS pipeline 不在本機跑，改用專用 Compute VM `evidence-runner`。

## 決策

原本有兩個候選：

- 沿用 `dev-vm`：既有 IAP / NAT / stop-start runbook 可直接用
- 新開 `evidence-runner`：多一個 VM stack，但身份與用途乾淨

最後採用 **專用 `evidence-runner`**。

理由：

- `dev-vm` 已偏 K8s / demo bastion，用途跟 evidence pipeline 不同
- evidence pipeline 需要讀寫 evidence bucket，若加在 `dev-vm` SA 上會混入 container 權限
- `evidence-runner` 可以只綁 bucket `objectViewer` + `objectCreator`
- VM attached service account 可透過 metadata server 取得短期 token，符合 ADR-002 不用 long-lived credential 的方向
